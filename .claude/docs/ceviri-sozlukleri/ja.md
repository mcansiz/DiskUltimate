表記: カタカナ複合語は原則スペースなしで続けて書く（ファイルシステム、バックアップファイル、プライマリパーティション）。英字と日本語の間には半角スペース（APFS ボリューム、{} 個）。

追加の決定:
- move forward / back（パーティション移動）: 末尾方向へ / 先頭方向へ（「前方/後方」は曖昧なため）
- Free space before / after: 前方の空き領域 / 後方の空き領域
- No to All: すべていいえ(&O)
- hibernation / Fast Startup: 休止状態 / 高速スタートアップ
- dirty flag: ダーティフラグ
- compression ratio "saved": 削減（{:.0f}% 削減）
- VHD fixed / dynamic: VHD 固定サイズ / VHD 可変長
- Secure Boot: セキュアブート
- refresh: 最新の情報に更新（ボタン）/ 更新
